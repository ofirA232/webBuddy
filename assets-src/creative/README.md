# עבודות קריאייטיב

כאן שמים את החומרים של סקשן הקריאייטיב באתר. אין שום קובץ קוד לערוך.

1. גוררים לכאן קבצים — תמונות (`png`, `jpg`, `webp`) או סרטונים (`mp4`, `mov`, `webm`), בכל גודל וכל יחס. סרטונים שכבר ביוטיוב נכנסים דרך `youtube.txt` שבתיקייה.
2. מריצים `npm run images`.

זהו. הקיר באתר מתמלא לבד, וכל אריח מקבל את הצורה של העבודה שבתוכו.

## סדר וקדימות

- **סדר התצוגה הוא סדר שמות הקבצים**, לכן כדאי להתחיל את השם במספר: `01-`, `02-` וכך הלאה.
- **הקיר מציג כמה שנכנס במסך אחד** — בערך 9 עד 12 עבודות בדסקטופ, תלוי בצורות שלהן (באנר רחב תופס מעט מקום, סטורי לגובה תופס הרבה). מה שלא נכנס פשוט לא מוצג, ולכן **שמים קודם את העבודות הכי חזקות**.
- עבודה שגבוהה מהמסך מוצגת במלואה בתוך אריח נמוך יותר, עם שוליים כהים משני הצדדים, כדי שלא ייחתך ממנה חלק.

## שמות וטקסט חלופי

**שם הקובץ הוא גם הטקסט החלופי** (מה שקורא מסך מקריא ומה שגוגל רואה). `באנר-קמפיין-קיץ.png` יהפוך ל"באנר קמפיין קיץ". עברית ואנגלית שתיהן עובדות.

לטקסט מדויק יותר אפשר להוסיף שורה ב-`OVERRIDES` בקובץ `client/src/data/creativeData.ts`.

## סרטונים מיוטיוב

עורכים את `youtube.txt` שבתיקייה הזאת — שורה לכל סרטון, `שם = כתובת` — ומריצים `npm run images`.

- **16:9 ו-9:16 שניהם עובדים.** הצורה נלקחת מהכתובת: קישור `/shorts/` מזוהה כאנכי, כל השאר כרוחבי. לצורה אחרת מוסיפים בסוף `| 4:5`.
- הסקריפט מוריד לבד את תמונת התצוגה מיוטיוב, חותך אותה לצורה הנכונה ושומר אותה מקומית. אם ההורדה נכשלת, האתר נופל חזרה לתמונה של יוטיוב ישירות, כך שהעבודה עדיין מוצגת.
- רוצה תמונת תצוגה אחרת? שמים קובץ בשם `<שם>.poster.jpg` באותה תיקייה והוא גובר.
- **באתר לא נטען כלום מיוטיוב עד שלוחצים.** האריח מראה תמונה וכפתור הפעלה; רק בלחיצה נפתח נגן על מסך מלא. נגן יוטיוב שוקל בערך מגה־בייט, וקיר של תריסר כאלה היה עולה יותר מכל שאר העמוד.

## סרטונים כקובץ

- דורש `ffmpeg` מותקן. בלעדיו התמונות עדיין עוברות והסרטונים מדולגים עם הודעה.
- הסרטון מומר אוטומטית לרוחב 900, **בלי פס קול** (הוא מתנגן מושתק בלולאה), ונוצרת לו תמונת פתיחה מהשנייה הראשונה.
- באתר הוא מתנגן בלולאה רק כשהוא על המסך, ונעצר כשיוצאים ממנו. למי שביקש פחות אנימציות במערכת ההפעלה הוא לא מתנגן לבד אלא מוצג עם כפתור הפעלה.
- **כדאי קליפים קצרים** — 3 עד 8 שניות. הקיר הוא טיזר, לא נגן.
- אם הסרטון ממילא ביוטיוב, עדיף `youtube.txt`: זה חוסך את המשקל מהמאגר.

## מחיקה

מוחקים את הקובץ מכאן, מוחקים את הקבצים שנוצרו ממנו ב-`client/src/assets/creative/`, ומריצים שוב `npm run images`.
