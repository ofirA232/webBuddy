# עבודות קריאייטיב

כאן שמים את החומרים של סקשן הקריאייטיב באתר. אין שום קובץ קוד לערוך.

1. גוררים לכאן קבצים — תמונות (`png`, `jpg`, `webp`) או סרטונים (`mp4`, `mov`, `webm`), בכל גודל וכל יחס. סרטונים שכבר באינטרנט (יוטיוב או פייסבוק) נכנסים דרך `videos.txt` שבתיקייה.
2. מריצים `npm run images`.

זהו. הקיר באתר מתמלא לבד, וכל אריח מקבל את הצורה של העבודה שבתוכו.

## סדר וקדימות

- **סדר התצוגה הוא סדר שמות הקבצים**, לכן כדאי להתחיל את השם במספר: `01-`, `02-` וכך הלאה.
- **הקיר מציג כמה שנכנס** — בערך 22 עבודות במסך רחב, 15 בלפטופ ו-18 במובייל, תלוי בצורות שלהן (באנר רחב תופס מעט מקום, סטורי לגובה תופס הרבה). מה שלא נכנס פשוט לא מוצג, ולכן **שמים קודם את העבודות הכי חזקות**.
- עבודה שגבוהה מהמסך מוצגת במלואה בתוך אריח נמוך יותר, עם שוליים כהים משני הצדדים, כדי שלא ייחתך ממנה חלק.

## שמות וטקסט חלופי

**שם הקובץ הוא גם הטקסט החלופי** (מה שקורא מסך מקריא ומה שגוגל רואה). `באנר-קמפיין-קיץ.png` יהפוך ל"באנר קמפיין קיץ". עברית ואנגלית שתיהן עובדות.

לטקסט מדויק יותר אפשר להוסיף שורה ב-`OVERRIDES` בקובץ `client/src/data/creativeData.ts`.

## סרטונים מיוטיוב ומפייסבוק

עורכים את `videos.txt` שבתיקייה הזאת — שורה לכל סרטון, `שם = כתובת` — ומריצים `npm run images`. **יוטיוב ופייסבוק שניהם עובדים**, ואפשר לערבב ביניהם באותו קובץ.

- **16:9 ו-9:16 שניהם עובדים.** הצורה נלקחת מהכתובת: קישור `/shorts/` או `/reel/` מזוהה כאנכי, כל השאר כרוחבי. אם הסרטון בפועל בצורה אחרת מוסיפים בסוף `| 1:1` למשל. **שווה לוודא** — ריל בפייסבוק יכול להכיל וידאו מרובע.
- הסקריפט מוריד לבד את תמונת התצוגה, חותך אותה לצורה הנכונה ושומר אותה מקומית. אצל פייסבוק התמונה נשלפת מדף ההטמעה, כי אין לה כתובת ציבורית קבועה.
- רוצה תמונת תצוגה אחרת? שמים קובץ בשם `<שם>.poster.jpg` באותה תיקייה והוא גובר. אם ההורדה נכשלת והקובץ לא קיים, הסקריפט יודיע לך.
- **באתר לא נטען כלום מיוטיוב או מפייסבוק עד שלוחצים.** האריח מראה תמונה וכפתור הפעלה; רק בלחיצה נפתח נגן על מסך מלא. נגן של כל אחת מהפלטפורמות שוקל בערך מגה־בייט, וקיר של תריסר כאלה היה עולה יותר מכל שאר העמוד.
- הבדל אחד: נגן יוטיוב מתחיל לנגן מיד, ונגן פייסבוק דורש עוד לחיצה על כפתור ההפעלה שלו. זו התנהגות של פייסבוק ואין עליה שליטה מבחוץ.

## סרטונים כקובץ

- דורש `ffmpeg` מותקן. בלעדיו התמונות עדיין עוברות והסרטונים מדולגים עם הודעה.
- הסרטון מומר אוטומטית לרוחב 900, **בלי פס קול** (הוא מתנגן מושתק בלולאה), ונוצרת לו תמונת פתיחה מהשנייה הראשונה.
- באתר הוא מתנגן בלולאה רק כשהוא על המסך, ונעצר כשיוצאים ממנו. למי שביקש פחות אנימציות במערכת ההפעלה הוא לא מתנגן לבד אלא מוצג עם כפתור הפעלה.
- **כדאי קליפים קצרים** — 3 עד 8 שניות. הקיר הוא טיזר, לא נגן.
- אם הסרטון ממילא ביוטיוב או בפייסבוק, עדיף `videos.txt`: זה חוסך את המשקל מהמאגר.

## מחיקה

מוחקים את הקובץ מכאן, מוחקים את הקבצים שנוצרו ממנו ב-`client/src/assets/creative/`, ומריצים שוב `npm run images`.
