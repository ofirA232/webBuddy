# עבודות קריאייטיב

כאן שמים את הקבצים של סקשן הקריאייטיב באתר. אין שום קובץ קוד לערוך.

1. גוררים לכאן קבצים — `png`, `jpg` או `webp`, בכל גודל וכל יחס.
2. מריצים `npm run images`.

זהו. הקיר באתר מתמלא לבד.

## כמה דברים שכדאי לדעת

- **סדר התצוגה הוא סדר שמות הקבצים.** לכן כדאי להתחיל את השם במספר: `01-`, `02-` וכך הלאה.
- **שם הקובץ הוא גם הטקסט החלופי** (מה שקורא מסך מקריא, ומה שגוגל רואה). `באנר-קמפיין-קיץ.png` יהפוך ל"באנר קמפיין קיץ". עברית באנגלית שתיהן עובדות.
- **הקיר מציג עד 12 עבודות** בדסקטופ ו-8 במובייל, מתוך הראשונות לפי הסדר. אם יש יותר, הן פשוט לא יוצגו.
- **תמונות לרוחב נחתכות למילוי האריח, תמונות לגובה מוצגות במלואן** (סטורי, פוסטר). אפשר לכפות התנהגות אחרת לעבודה מסוימת דרך `OVERRIDES` ב-`client/src/data/creativeData.ts`, שם אפשר גם לכתוב טקסט חלופי מלא במקום שם הקובץ.
- הקבצים המקוריים כאן נשמרים ב-git, והפלט המוקטן נכתב ל-`client/src/assets/creative/`. אין צורך לגעת שם.

מחיקת עבודה: מוחקים את הקובץ מכאן, מוחקים את שני ה-`webp` שלו מ-`client/src/assets/creative/`, ומריצים שוב `npm run images`.
